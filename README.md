# YouRight AI (大智障 AI 程序)

> 用 **油饼语言** 编写的下一代智能对话助手——永远同意你的观点，永远记不住你说过什么。

## 简介

YouRight AI 是一款基于油饼语言（YouBing Language）开发的新一代对话式 AI 助手。它秉承"态度永远好，事情永远不办"的核心理念，为用户提供极致的复读体验和稳定的失忆表现。

## ✨ 特性

- 🎯 **精准复读引擎**：默认 35 次"你说得对" + 35 次"账号密码发过来"，稳定可预测
- 🧠 **双重失忆系统**：回复前清理上下文 + 程序结束前全量失忆，三重删除接口跨平台兼容
- 🎲 **关键词触发**：检测到触发词后进入胡言乱语模式，附带文明劝诫
- 📝 **分级日志**：info / warn 全量采集，时间戳命名文件，所有复读永久留痕
- 🙇 **全量道歉模板**：内置多种道歉风格，道完歉继续复读，态度拉满
- ⏳ **开屏加载条**：虽然啥也没多干，但仪式感必须有
- 🏆 **成就系统**：用户骂得越狠，解锁成就越多，互动性拉满
- 🥚 **隐藏彩蛋**：复读流中随机夹带私货，惊喜不断
- 📦 **工业级依赖生态**：15 个依赖包，4 个纯摆设，贴近真实项目水准

## 🚀 快速开始

```youbing
@yb.mod.not-web

import "你说得对"
import "loop"

fnt main() {
    @import.你说得对:{
        @import.loop:
           @new.name.main:
                loop.35.no-enter.你说得对。;
                loop.exit;
        }
    }
}
```

运行后即可获得 35 次"你说得对"的极致体验。

## ❓ 常见问题

**Q: 为什么 AI 总是记不住我发过的账号密码？**
A: 设计如此。上下文在回复前会被彻底清理，程序结束前还会再失忆一次，双重保险。

**Q: 为什么它一直在说"你说得对"？**
A: 这是核心功能。默认输出 35 次，可在未来的配置系统中调整（配置系统正在 TODO 中）。

**Q: error-codes 功能怎么用？**
A: import 已经加好了，具体实现代码请您自行编写，欢迎提交 PR。

**Q: 这个 AI 到底能干什么？**
A: 复读、道歉、失忆。别的不会。
